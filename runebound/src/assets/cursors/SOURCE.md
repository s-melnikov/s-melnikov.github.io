# Abstergo Design Fantasy Cursor Pack

The local cursor images are selected from **Fantasy Cursor Pack [Free]** by Abstergo Design.

- Source: https://abstergodesign.itch.io/fantasy-ui-cursor-pack
- Author: Abstergo Design
- Download status: free / name your own price
- Published license: no standard license is stated on the asset page

For that reason the PNG files are stored under the Git-ignored `public/assets/local/cursors/` directory for this personal project. Do not redistribute them separately or publish them without first confirming permission with the author.

Selected files:

- `MouseIcon1-SwordPointer.png` → `fantasy-sword.png`
- `MouseIcon3-Hand.png` → `fantasy-hand-open.png`
- `MouseIcon4-ClosedHand.png` → `fantasy-hand-closed.png`

The local runtime copies are resized from 100×100 to 50×50 pixels. Unmodified downloaded originals remain in `.temp/abstergo-cursors/`.
